CORE PRINCIPLE

ClaimGuard follows this architecture principle:

"AI reads the case; deterministic rules verify the case."

AI/VLM/OCR may:
- read documents
- extract structured information
- classify documents
- interpret policy language
- identify potentially relevant clauses
- summarize evidence
- draft explanations/appeal content

AI/VLM/OCR must NOT independently:
- decide financial correctness
- invent missing values
- fill missing values with zero
- decide medical necessity
- override deterministic rules
- fabricate evidence
- produce a successful adjudication when critical evidence is missing
- convert uncertainty into false certainty

Deterministic components must remain responsible for:
- policy applicability
- rule evaluation
- financial calculations
- deductions
- reconciliation
- dependency ordering
- threshold evaluation
- final financial assertions

Human review must remain the fallback for:
- missing evidence
- conflicting evidence
- insufficient extraction confidence
- policy ambiguity
- unsupported rule interpretation
- clinical necessity
- uncertain document identity
- unresolved contradictions
- provider/VLM failure where required evidence cannot be recovered
